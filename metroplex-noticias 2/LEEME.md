# Metroplex Noticias — Landing page

Código completo del sitio (TanStack Start + React + Tailwind CSS).

## Cómo correrlo en tu computadora
1. Instala Node.js 20 o más reciente (o Bun).
2. En esta carpeta ejecuta: `npm install`
3. Para verlo: `npm run dev` y abre la dirección que aparece en pantalla.
4. Para publicarlo: `npm run build`

El número de WhatsApp y los enlaces a Facebook, YouTube y la web están en `src/lib/contact.ts`.
